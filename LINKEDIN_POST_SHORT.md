## Headline: I built a high-fidelity music app and brought it to Android. Here’s how. 🎧📱

I’m excited to share **Vibe On** — a project I’ve been building to showcase my skills in modern full-stack development and mobile integration.

What started as a React web app is now a fully functional Android application, complete with cloud sync, premium audio features, and a stunning UI.

### 🚀 Key Highlights:
- **Web to Android**: Used **Capacitor** to bridge the gap, implementing native Android behaviors like hardware back-button support and dynamic status bar styling.
- **Tinder-style 3D Discovery**: Swipe through albums with a fluid, 3D gesture-driven interface.
- **Synced Lyrics & Pro Audio**: Apple Music-style lyrics and a 10-band equalizer for the audiophiles.
- **Cloud Powered**: Seamless Google Auth and library sync across devices using **Supabase**.

### 🛠️ The Stack:
- **Frontend**: React 18, TypeScript, Tailwind CSS, Framer Motion.
- **State**: Redux Toolkit (Thunk + Listeners).
- **Native**: Capacitor (Android 15 / SDK 35 support).
- **Backend**: Supabase (Auth, RLS, Cloud DB).
- **CI/CD**: Automated signed AAB builds via GitHub Actions.

I built this from the ground up to demonstrate my dedication to learning and my ability to implement complex, high-performance features. This app is a showcase of my journey toward becoming a world-class software engineer.
