# Vibe On - Play Store Description

## Short Description
A premium, high-fidelity music experience with 3D discovery, synced lyrics, and a pro-grade equalizer.

## Full Description
Experience music like never before with **Vibe On** — the ultimate music player designed for audiophiles who crave a premium, immersive, and highly personalized listening experience.

### 🌟 Featured Highlights:
- **Tinder-style 3D Discovery**: Swipe through a stunning 3D card stack of albums to discover your next favorite track. Left to skip, Right to play.
- **Apple Music-style Synced Lyrics**: Follow along with beautifully animated, time-synced lyrics that bring you closer to the music.
- **High-Fidelity Visualizers**: Choose from 5 premium canvas visualizers (Particles, Circular, Waveform, and more) that dance to every beat with physics-based smoothing.
- **Pro 10-Band Equalizer**: Take total control of your audio with a professional graphic equalizer and custom presets.
- **Gapless Playback & Crossfade**: Enjoy seamless transitions between songs for an uninterrupted flow.
- **Cloud Sync & Privacy**: Securely sync your library and settings across devices using Google OAuth and Supabase Cloud.

### 🎨 Stunning UI/UX:
- **Dynamic Theme Engine**: The app's accent color automatically syncs with your current album art for a cohesive visual experience.
- **OLED Mode**: Save battery and enjoy deep blacks with our dedicated OLED theme.
- **Glassmorphism Design**: A modern, sleek interface built with React and Framer Motion.

### 🛠️ Developer's Journey:
Vibe On is more than just a music app; it is a labor of love and a showcase of technical mastery. I built this application from the ground up to push the boundaries of what's possible with modern web technologies and native Android integration.

Every line of code — from the complex canvas math in the visualizers to the robust Redux state management and the native Capacitor integration — was written to demonstrate my skills as a software engineer. This app is a testament to my dedication to learning, implementation, and creating world-class user experiences.

---
**Note**: Vibe On is a portfolio project created for learning and demonstration purposes. It utilizes the JioSaavn API to provide a rich catalog of music for testing and showcasing its features.

### Technical Stack:
- **Frontend**: React 18, TypeScript, Tailwind CSS
- **Animations**: Framer Motion
- **State Management**: Redux Toolkit (Thunk + Listeners)
- **Backend**: Supabase (Auth, DB, RLS)
- **Native**: Capacitor v8
- **Audio Engine**: Custom Web Audio API implementation
